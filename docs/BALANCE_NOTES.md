# v1.1.0 表記・バランス調整メモ

2026-11-23の依頼に基づく調整です。正式版v1.0.0のタグ・ZIPは維持し、変更をv1.1.0へまとめます。

## 表記の基準

原作の日本語・英語localizationにあるホログラム、カイーノ、ToDoリスト等を参照しました。公開されている原作ファイルの再掲であり、ユーザーのインストール済みゲームファイルを直接取得したものではありません。

- 成長するXMultの増加量は、ホログラムと同じ赤背景・白文字の `{X:mult,C:white}` を使う。
- `X0.05を得る` は保存倍率へ0.05を加える成長。現在倍率を0.05倍する効果ではない。通常の `+8 Mult` は赤文字の足し算として区別する。
- 現在の倍率は、本文末尾の「（現在 倍率X…）/ (Currently X… Mult)」へ置く。
- サタンは初期倍率・人数による加算・ボス成長を先に説明し、最後に実際の総倍率だけを表示。内部計算の人数・成長値は本文へ詰め込まない。
- 咲の対象を「プレイした一番左のカード / Leftmost played card」と明記。得点対象・未強化・1ブラインド1回の条件と演出順は維持する。
- ほかのカードも、固定XMultは赤枠、通常の加算Multは赤文字、加算チップは青文字とし、日本語の「倍率X…」「チップ+…」を統一する。

## 比較と判断

|参照先|比較した性質|今回の判断|
|---|---|---|
|原作ToDoリスト|指定役を出すたび$4|神谷の$3は据え置き、1ブラインドの上限だけを外す|
|原作バガボンド|所持金条件を満たすハンドごとのタロット生成|神谷は3スーツが必要で、生成も通常1/4。確定の毎ハンド生成にはしない|
|原作ホログラム／カイーノ|XMultを加算して育成し、現在値を末尾に表示|東雲・サタンの表記だけを統一し、成長量・成長タイミングは維持|
|PokermonのPsyduck|フェイス1枚だけをプレイした際の$3報酬|条件を満たすプレイを繰り返して稼ぐ方針を参考にし、神谷の条件と報酬を両立|
|PokermonのMeowth／Persian|ラッキーカードの成功で終了時収入が育つ経済型|神谷にさらに永続的な金額成長は加えず、発動機会を増やす|
|Jester's PrivilegeのDredd Joker|1/4で特定タロットを生成|神谷はランダムタロット1/4とし、空き枠・予約枠・確率変更の標準APIを維持|
|Jester's PrivilegeのHudson／Buzzer Beater|ハンドやボス撃破によるXMult成長|サタンは成長速度を増やす代わりに、初期値だけ+0.5とする|
|Cryptid|作者自身がunbalanced modと位置付ける大幅拡張|大きい数値を直接合わせる基準にはせず、原作寄りの範囲で調整する|

MODごとに想定する強さや独自ルールは異なります。上表は効果設計の比較であり、各MODと同時に起動した実ゲーム互換性や、同等の勝率を確認した結果ではありません。一部MOD Wikiは403で本文を取得できなかったため、公開ソース・作者の説明を優先しました。

## 神谷幸広

3種類のスートを得点カードへ割り当てられるハンドごとに$3とタロット抽選。満杯でも$3を得ます。

|同じブラインドの条件達成ハンド数|v1.0.0の収入|v1.1.0の収入|
|---:|---:|---:|
|1|$3|$3|
|2|$3|$6|
|4|$3|$12|

追加のハンドを使えば通常は未使用ハンド報酬$1を失うため、金額も同時に引き上げることは避けました。タロットは各ハンドで抽選し、4回成功条件を作った場合、空き枠を無視した抽選成功の期待値は通常1枚です。実際の生成数は空き枠に依存します。

同じハンドの重複評価とジョーカー再発動では追加報酬を出しません。Blueprint/Brainstormは各コピーの使用記録と生成予約を共有し、各コピー1回ずつ発動できます。旧セーブのブラインド使用フラグは新しいハンド単位の管理へ移行します。

## サタン

計算式を `X(2.5 + 0.25 × 有効な異種メンバー数 + 保存成長値)` に変更。

|状態|v1.0.0|v1.1.0|
|---|---:|---:|
|メンバー0人・成長なし|X2|X2.5|
|5人・成長なし|X3.25|X3.75|
|3人で5ボス撃破後|X5|X5.5|

ボス撃破時の成長は1人につき0.15、最大0.75のまま。初動の弱さを緩和し、長期の成長速度は増やしません。サタンの枠、重複人数の扱い、無効化、保存成長は維持します。

## 検証範囲

Lua 5.1、能力ロジック、表示変数・赤枠・末尾の現在値、旧セーブに相当する状態、コピー・生成予約、パッケージを自動検証。実ゲームでの文章の収まりと難易度の確認はユーザー側で行います。神谷・咲のソロお題と最終お題は今回の上方調整で有利になるため、手数・資金の難易度確認対象です。
