# Cafetro! — ジョーカー能力仕様書 v1.2.0

現行の数値は `Cafetro/config.lua` に集約する。v1.1.0では依頼に基づき神谷とサタンを上方調整。比較資料と判断理由は `BALANCE_NOTES.md` を参照。

## 共通定義
- 追加するカードは `kamiya` / `shinonome` / `aslan` / `makio` / `saki` / `satan` / `cake_set` / `chocolate_spacial` / `plain_cakeroll` / `three_one_five` / `embossing` / `sunsun` / `goldpeople` / `amehiko` / `sora` / `koron` の16種。表示名 `Cafetro!`、内部MOD ID `CafeParade`。内部IDの完全形はSteamoddedのprefix規則に従って衝突しないものにする。
- 「Café Paradeメンバー」は **神谷・東雲・アスラン・巻緒・咲の5種のみ**。サタンは6枚目だがメンバー数には数えない。異なるメンバーを数えるときは種類ごとに最大1、同名2枚を所持しても1人。
- 「所持している」はジョーカー領域に存在する有効（非debuff）のカードを意味する。Blueprint / Brainstormによる能力コピーは所持人数を増やさない。デッキにカードがあってもジョーカー領域になければ対象外。
- 「得点したカード」はスコア計算に参加したカード。捨て札、得点に不参加の手札、手札に残るスチールカード等は対象外。
- 「ペアを含む」は、得点対象の通常のランクを持つカード間に同一ランク2枚以上が存在する場合。ツーペア・スリーカード・フルハウス・フォーカード・ファイブカード等も対象。ランクが実質無効のストーンカードは対象外。追加手役系MODとの相性はベストエフォート。
- `1ブラインドに1回` と `1ハンドに1回` のフラグを個別に管理。ブループリントによる効果の複製は可能な範囲で認めるが、元カードのフラグを消費/成長させたり同一イベントで二重処理を起こさせない。
- 乱数はゲームのシードに連動した決定的な方式を使い、Lua標準の `math.random()` に依存しない。
- 倍率は `+Mult` と `XMult` を厳密に区別。`XMult` は乗算。

## 1. 神谷幸広 / Journey JOY Blend
- rarity: Uncommon (2)、shop cost: $6、色: `#D88B83`
- 条件: 得点したカードのスートとして、同一ハンド内に **3種類以上の異なるスートを割り当て可能**であるハンドごとに効果発動。
- 効果: **$3獲得**。さらに **1/4の確率**でランダムなタロットカード1枚を作成。消耗品スロットに空きがないときタロットは生成しないが、$3は得る。同一ハンドの重複評価・ジョーカー再発動では二重発動せず、次のハンドでは再び発動できる。Blueprint/Brainstormのコピーは同一ハンドで各1回ずつ発動できる。
- ワイルドカードは1枚で複数スートを水増ししない。各得点カードに有効なスート候補集合を考え、カード1枚につき最大1スートを割り当て、異なるスート3種類が成立する場合に成功とする。
- 《スメアードジョーカー》などスート判定を変える要素は反映。候補集合は原則Steamodded/Balatroの有効スート判定を用いる。もし具体的実装が難しければテスト対象として報告すること。
- ジョーカー効果は得点結果と同一ハンドで1回。タロット生成は二重に発生しないよう得点処理後の安全なタイミングに実行。
- シナジー: 咲のワイルド化、フラワーポット、スメアードジョーカー、占い師。

## 2. 東雲荘一郎 / Sweet Diamant
- rarity: Uncommon (2)、shop cost: $6、色: `#008E74`
- 初期保存値: `xmult=1.00`。
- 条件: 「ペアを含む」得点ハンド。
- 効果: その得点計算で **+8 Mult**。さらに **1ハンドに1回、得点終了後の演出と同時に永続のXMultを+0.05**。成長分は次のハンドから適用する。
- `context.after` で成長を予約し、得点演出後のイベント内でX倍率・ポップアップ・効果音・カードの動きを同時に更新する。表示は「成長！X1.05 / Upgraded! X1.05」など、成長後の値を示す。
- 演出待ちの成長は `ability.extra.pending_growth` に保存する。ロード時には未反映分を1回だけ確定し、同じハンドで再び成長させない。
- 成長はカード再発動の回数には連動しない。ブループリントなど能力コピー時、現在の成長済み倍率をコピーしてよいが元カードに二重成長を生じさせない。
- 売却や破壊でその個体の保存値は失われる。セーブ・復帰では維持。
- シナジー: 巻緒、デュオ、スペアトラウザーズ、DNA、ブループリント。

## 3. アスラン＝ベルゼビュートⅡ世 / 暗黒への前奏曲
- rarity: Rare (3)、shop cost: $8、色: `#6967AB`
- 条件: **強化（Enhanced）されている得点カード**1枚がスコア計算されるたび。
- 効果: そのカードの得点時に **X1.25 Mult**。レッドシール・ハンギングチャド・巻緒などの追加発動でもそれぞれ適用。
- ワイルド、ガラス、ラッキー、マルチ、ボーナス等の強化カードが対象。強化のないレッドシールのみのカードは対象外。
- 「手札にあるだけ」の強化カードには発動しない。1枚で複数の強化として数える特殊MODの仕様は現行Steamodded APIに沿って検討。
- シナジー: 咲、巻緒、ハンギングチャド、ガラス、レッドシール、DNA。

## 4. 卯月巻緒 / GIVE ME × FUSION
- rarity: Rare (3)、shop cost: $8、色: `#EEC362`
- 条件: 「ペアを含む」得点ハンド。
- 効果: 対象ランクの**得点カードのうち左から最大2枚を、それぞれ1回追加発動**させる。
- 対象ランク選択: 得点カード内で同じランクのカードが2枚以上存在するランク群から、**そのハンドで一番左の該当カードを持つランク群**を選ぶ。そのランク群の左から2枚を再発動。2ペア・フルハウスでも最大2枚。
- ブループリントで巻緒をコピーした場合は、元の巻緒とコピー分の再発動がそれぞれ発生してよい。ただし再発動判定が自分自身を呼び続けて無限ループしないこと。
- シナジー: 東雲、アスラン、ハンギングチャド、ガラス、ブラッドストーン、デュオ。

## 5. 水嶋咲 / Make up↑ Magic
- rarity: Rare (3)、shop cost: $8、色: `#EB6EA5`
- 恒常効果: **得点するワイルドカード1枚の発動ごとにX1.20 Mult**。レッドシール等の再発動でも効果を適用。
- 変化効果: **1ブラインドに1回**、`context.full_hand[1]`（プレイしたカード全体の一番左）**だけ**を判定し、未強化の通常カードで、`context.scoring_hand` に含まれる場合だけ **Makeup!の演出 → ワイルド化 → 得点演出** の順で永続変化させる。
- 左端が得点対象外、ワイルド・ほかの強化カード・消滅／破壊／粉砕済みなら不発。中央や右の未強化カードへ対象を移さず、使用回数も消費しない。次のハンドでプレーンなカードを左端へ移せば再挑戦できる。
- 得点対象外の左端カードは変化せず、得点する中央・右のカードへも対象を移さない。得点対象が空・未提供の場合も不発とし、使用回数を維持する。プレイせず手札に残したカードは対象外。シールやエディションだけなら未強化として扱い、それらは保持する。
- 変化は `context.before`（得点前）で行う。対象が得点するカードなら、そのハンドから咲のX1.20やアスランの強化カード効果が適用される。手役判定と得点対象は変化前に確定したものを使う。
- Steamoddedの同期計算に合わせ、能力は得点前に確定し、見た目は `delay_sprites` で遅延する。ポップアップ予約、0.4秒の待機、見た目の変更、得点演出の順を保つ。消滅・破壊・粉砕済みのカードは選ばない。
- コピーによる変化は1ブラインド1枚までを基本とし、Blueprintで複製できるのは得点時XMultのみとする（意図しない大量ワイルド化防止）。
- シナジー: アスラン、神谷、ブラッドストーン、フラワーポット、エンシェントジョーカー、ハンギングチャド。

## 6. サタン / 暗黒の祝福
- rarity: Legendary (4)、shop cost: 通常ショップに置かない想定（価格はAPIの既定/適切な設定を採用）。色: **`#777B85` グレー**。
- 有効所持中は**ジョーカー所持上限+1**。1枚のサタンにつき+1枠でよいが、コピー効果では枠を増やさない。売却・破壊・debuffで解除し、再有効化時に再加算。セーブ/ロードで二重加算しない。
- 得点時XMult: **X(2.50 + 0.25×現在の異なるCafé Paradeメンバー数 + 永続成長値)**。
- 初期永続成長値: `0.00`。**ボスブラインドを撃破したとき、異なるメンバー数×0.15 を永続的に加算**。ボスにつき1回のみ。コピーでは成長しない。
- 例: メンバー3人・ボス5回撃破後の成長値 `3×5×0.15=2.25`、現在のXMultは `2.5 + 0.75 + 2.25 = X5.50`。
- 所持メンバー数が減ると「0.25×現在人数」の部分は減るが、すでに獲得した永続成長値は維持する。
- 通常のレジェンダリーと同様の入手経路（The Soulなど）が使えるよう、rarity=4 の正しい登録方法を確認する。入手経路を自作で無理に追加しない。
- ほかのサタンを同時所持する際の挙動もテストする。サタンを売却するとジョーカー枠が現在カード数未満になる場合でも即時クラッシュしないこと。
- シナジー: 全メンバー＋ブループリント（得点時XMultのみ）。

## 7. ケーキセット / Cake Set
- rarity: Common (1)、shop cost: $4。
- **ペアを含む役**なら、得点中にボスのスートによるカード無効化を解除する。原作スライジョーカーと同じ `context.poker_hands.Pair` の非空判定。ツーペア・スリーカード・フルハウス・フォーカード・ファイブカード・フラッシュハウス等も対象。
- 対象は標準の4ボス: クラブ（Clubs）・ゴード（Spades）・ウィンドウ（Diamonds）・ヘッド（Hearts）。ボスの無効化フラグは変更しない。顔・ランク・過去にプレイしたカード等の制限、ほかのボス、別原因のデバフは解除しない。
- プレイしたカードと手札のカードに適用する。ワイルドや手札のスチールも対象。そのハンドの得点演出後に通常のスート制限へ戻す。
- 判定は `context.before.poker_hands.Pair` を使い、咲がワイルド化した後に手役を判定し直さない。咲との左右の順序に依存しない。
- ケーキセットが無効化・売却された場合は解除効果を失う。複数所持でも範囲は変わらず、最後の有効な1枚を失った時点で通常の制限へ戻す。
- Blueprint/Brainstormでコピー不可。サタンのメンバー数には含めない。お試しライブの初期6枚にも追加しない。
- ラウンド終了時、各実物カードにつき1回、通常1/5で食べられる。原作の `k_eaten_ex` と標準破壊APIを使用。`pools = {Food = true}` を持ち、エターナル生成の対象外。共通の隠し効果は後述。

## 8. Chocolate Spacial
- rarity: Rare (3)、shop cost: $8。画像は `Chocolate_spacial_joker.png`。名前は日英とも **Chocolate Spacial**、説明は日英対応。
- 役名が **フラッシュハウス（内部名Flush House）** のハンド終了後に、ランダムなスペクトルカードを2枚生成する。フルハウス・フラッシュ・フラッシュファイブなどでは発動しない。
- 消耗品に空きが必要。空きが1枠なら1枚、満杯なら0枚。予約済みの枠を含めて計算し、神谷やコピーによる生成と競合しても上限を超えない。
- スペクトルの選択はキーを指定せずSteamodded標準のシード付きカード生成に委ねる。
- 各ハンドで、本体と各Blueprint/Brainstormコピーがそれぞれ1回ずつ発動できる。重複評価やジョーカー再発動では追加生成しない。次のフラッシュハウスなら同じブラインドでも再度生成する。
- サタンのメンバー数には含めない。既存の開発用fixtureの初期6枚構成は維持する。本文だけで説明し、補足ツールチップは追加しない。

## 9. ロールケーキ / Plain cakeroll
- rarity: Common (1)、shop cost: $4。画像は `Plain_cakeroll_joker.png`。日英対応で、補足ツールチップは追加しない。
- **得点対象がちょうど2枚**なら、その2枚が得点するたびに各 **+50 Chips**。プレイ枚数や役名は条件にしない。5枚プレイ・2枚得点でも発動する。
- `context.individual`・`G.play`・得点対象枚数2枚に加え、対象カードが `scoring_hand` に含まれることを確認する。手札に残るカードや得点しないカードには与えない。
- 2枚の基本発動なら合計+100チップ。レッドシール・巻緒などの再発動でも各回+50チップ。Blueprint/Brainstorm・複数所持にも対応する。
- ストーンが得点対象へ加わって3枚になった場合は不発。2枚ならペア以外の組み合わせにも適用する。サタンのメンバー数には含めず、開発用fixtureの初期6枚構成も維持する。
- ラウンド終了時、各実物カードにつき1回、通常1/10で食べられる。`pools = {Food = true}`、エターナル生成の対象外。チップ効果だけをコピーでき、消滅抽選はコピーしない。

### フード共通の隠し効果・寿命

- ケーキセットかロールケーキのいずれかを有効所持すると、巻緒の抽選重みが1.25倍。両方・複数所持・Blueprintで加算しない。売却・消滅・デバフ中は無効で、別の有効な1枚があれば継続。
- レアリティ自体の出現率や巻緒の禁止・アンロック・重複制限は変えない。実際の出現率が一律1.25倍になるのではなく、同じ抽選プールの他カードとの相対重み。日英のカード説明・補足・プレイヤー向けREADMEには記載しない。
- `food.lua` で原作方式の等重み抽選を補正し、object_weights有効時は巻緒の `get_weight` を使う。金人間のコピーした抽選プールにも対応する。プールやグローバルなレアリティ重みは書き換えない。
- 食べられる判定は勝利したラウンド終了時の `main_eval` に限定。Blueprint・ジョーカー再発動・個別カード評価では抽選せず、ラウンド単位の保存ガードで二重抽選を防ぐ。旧ロールケーキの `ability.extra` 未設定も移行する。確率変更には標準APIを使い、表示にも反映する。
- 現行のエターナル生成は不可。旧セーブに既存のエターナルがある場合は消滅させない。ほかのMODによる破壊防止は `SMODS.destroy_cards` に委ねる。
- Foodは本体の公式レアリティではなく、対応MOD間で使われる追加プール。共有 `Food` メタデータで連携し、特定MODの独自フードシステムを一律に保証しない。

## 10. THREE ONE FIVE
- rarity: Rare (3)、shop cost: $8。画像は `315_joker.png`。日英対応。
- プレイしたハンドに **ランク3と5の両方** が含まれ、そのうち **少なくとも1枚が得点する** と、ジョーカーの得点処理時に **X3.15**。3のペア＋得点しない5、5のペア＋得点しない3でも発動。該当カードが複数でもカードごとの乗算はしない。
- `context.joker_main` で、`context.full_hand` に3と5がそろっていることを確認したうえで、`context.scoring_hand` に無効化されていない3か5があるかを確認する。ストーンなど `SMODS.has_no_rank` のカードは両方の判定から除外。無効化されたカードもプレイしたランクの存在には数えるが、それ自体では得点条件を満たさない。手札に残るカードは数えない。
- Blueprint/Brainstorm・複数所持・ジョーカー再発動は標準のジョーカー計算に従う。得点カードの再発動だけでは倍率を追加しない。サタンのメンバー数・開発用fixtureの初期6枚構成には含めない。
- 説明文末尾に `{C:inactive,s:0.6}` を使い「アイドルマスターSideM×FiFS展 THREE ONE FIVE」を小さなグレー文字で表示。日英とも元ネタ表記は指定された文言を保持する。
- 共通アトラスは5列で折り返し、新カードは `x=4,y=1`。サタンのベースは `x=0,y=1`、独立前景は従来の `x=0,y=0`。

## 必須テスト観点
1. 各ジョーカー単体・Café Parade組み合わせ・vanilla Joker組み合わせ。
2. すべてのジョーカーについて通常、無効化、売却、破壊、複製、セーブ／再開。
3. 1枚カード、ペア、ツーペア、フルハウス、フォーカード、ファイブカード、ストーン、ワイルド、ガラス、スチール、レッドシール。
4. Blueprint / Brainstorm で得点時効果は妥当にコピーされ、永続効果や増枠が二重にならない。
5. ボス撃破（サタン）、同じラウンドの再評価、ワイルド化（咲）の遅延、タロット枠満杯（神谷）。
6. 変化や育成の保存・復帰、再発動の停止性、アトラス位置。

## 意図した妥協点
- すべての現存MODとの完全互換は要求しないが、バニラおよび現行Steamodded標準の仕様と整合させる。
- 神谷の「候補スートを3種類へ割り当てる」処理が互換性上重すぎる場合は、結果を安易に変えず問題点を報告し代替案を提案する。
- テキストは画面に合わせて短縮してよいが、実際の機能や発動条件は変えない。

## v1.0.0のお題

- `challenges/member_challenges.lua` で5つのソロお題と最終お題を登録。各ソロは主役1枚をエターナル所持、他の4人とサタンを禁止する。通常ランの能力・プールは変更しない。
- 初期所持・制限・攻略の狙いは `CHALLENGE_GUIDE.md`。標準の `rules.custom` / `rules.modifiers` / `restrictions` を使用し、独自のスコア処理やグローバルなルールフックを加えない。
- 最終お題は、選択中プロフィールの `challenge_progress.completed` に5つの `c_cp_solo_*` がそろったときだけ解放。プロフィール未初期化や記録なしはロック。通常ランの勝利は数えない。標準の `SMODS.challenge_is_unlocked` による `all_unlocked` は尊重する。
- 最終お題は5人＋サタン全員エターナル、基本5枠＋サタン1枠。2ハンド・1ディスカード・手札7枚、標準52枚。標準の `scaling=3` でパープルステーク相当の要求スコア上昇を使う。
- 最終お題は利息・残りハンド報酬を禁止。ショップ・パック・タグ・消耗品による追加ジョーカーと、反物質・エクトプラズムによる空き枠を禁止する。全員売却不可のためヴァーダントリーフを除外。
- 最終お題の未解放表示は標準のロックUIを使う。日英対応。お試しライブは開発用fixtureとし、配布版では登録しない。

## v1.1.0の説明表記

## 14. 葛之葉雨彦 / Amehiko Kuzunoha

- 対象は `G.jokers.cards`・`G.consumeables.cards`・`G.playing_cards` の和集合。MODが登録を遅らせるトランプ用に、deck・hand・play・discard領域も集計する。同一実体は1回だけ数え、ショップ・パック・コレクションの未所持プレビューを含めない。

- 日英本文はネガティブ1枚あたりのX0.25・ネガティブ固定・末尾の現在倍率。加工増加量と現在倍率は赤枠で表記し、追加の補足ツールチップは設けない。
