# Cafetro! v1.0.0 検証

リポジトリのルートで `python tests/run.py` を実行します。Python 3.12、Pillow 12.0.0、Lupa 2.8のLua 5.1で確認しています。

## 自動検証

- 全ランタイム・fixture・テストのLua 5.1構文。
- 358件: ジョーカー10種の登録・能力・コピー・再発動・成長演出・状態復元・サタンの枠・日英説明。開発用のお試しライブが通常登録されないことも確認。
- 162件: ケーキセットのワンペア限定・スート制限だけの解除と復帰、他の無効化原因との共存。
- 140件: Chocolate Spacialの生成条件・容量・予約枠・複数所持とコピー。
- 401件: ソロお題5種＋最終お題の初期所持と制約、クリア全32通り、プロフィール分離、5つ目のクリア直後の解放、日英ルール、初期6枠。
- スキン4スート・2配色、画像全52セル。統合元のトランプ4枚と作者の利用案内をSHA-256で照合。
- nearest/lanczos、1x/2xのアトラス全画素・透明度・サタン前景・MODアイコン。配布する追跡済み画像とnearest再生成結果も一致。
- 配布ZIPの31ファイル、CRC、原稿・テスト・資料・仮プレビューの除外、SHA-256、再現可能なZIP内容、必要ファイル欠落時の失敗。
- **展開した配布ZIPだけ**を読み、ジョーカー10種・お題6種・スキン4種と全アトラスを登録。内部IDを保持し、追加の開発ファイルに依存しないことを確認。
- 後から作者が用意するREADMEはそのまま同梱でき、自動生成しないことを確認。

ロジックは合計1,061アサーション。モックはゲームの描画・セーブ形式・Steamoddedディスパッチ全体を再現しません。ZIPの読み込み確認も、実ゲーム起動の代用ではありません。

## ユーザー側での実ゲーム確認

1. 旧版と二重導入せず、`Cafetro` フォルダで起動。表示名Cafetro!、新アイコン、ジョーカー10枚、日英の説明・作者表記を確認。
2. 通常ランと既存セーブを確認。内部ID・prefix・カードキーは維持しているが、実際の保存形式との互換はこの環境では未確認。
3. 咲の左端限定Makeup!→ワイルド→得点、東雲の得点後成長、ケーキセットのスート制限解除、生成・再発動・サタンの枠を確認。
4. ソロ5種の開始状態と制限、同じプロフィールで5種クリアしたときの最終お題解放、再起動・別プロフィールでの状態を確認。
5. 最終お題の6人・6枠・2ハンド・1ディスカード・要求スコア・報酬制限と、クリア可能性・難易度を確認。
6. スキンの通常色／ハイコントラスト、1x／2x、設定保存と標準スキンへの復帰を確認。

旧版の検証記録は `history/TEST_RESULTS.md` に保存しています。
