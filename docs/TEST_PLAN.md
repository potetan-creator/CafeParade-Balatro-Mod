# Cafetro! v1.2.0 検証

リポジトリのルートで `python tests/run.py` を実行します。Python 3.12、Pillow 12.0.0、Lupa 2.8のLua 5.1で確認しています。

## 自動検証

- 全ランタイム・fixture・テストのLua 5.1構文。
- 612件: ジョーカー12種の登録・能力・コピー・再発動・成長演出・状態復元・サタンの枠・日英説明。開発用のお試しライブが通常登録されないことも確認。
- 咲の左端が得点対象外・得点対象が空／未提供なら変化・演出・回数消費なし。同じブラインドの次の有効なハンドで発動でき、得点対象の配列順が変わってもプレイした左端を選ぶことを確認。
- 神谷の同一ブラインド内4ハンド連続報酬、重複評価・コピー・旧セーブ移行、失敗したタロット抽選・満杯・可変確率を確認。サタンの0〜5人時のX2.5〜X3.75、人数減少後と旧成長値の保持、赤枠と末尾の現在値を日英で確認。
- エンボスの全標準強化・シール／エディションのみの除外・再発動・コピー、スンスンの6限定・得点対象との一致・ストーン除外・コピー・非得点領域の除外、日英の最終行の非公式表記を確認。
- 162件: ケーキセットのワンペア限定・スート制限だけの解除と復帰、他の無効化原因との共存。
- 140件: Chocolate Spacialの生成条件・容量・予約枠・複数所持とコピー。
- 401件: ソロお題5種＋最終お題の初期所持と制約、クリア全32通り、プロフィール分離、5つ目のクリア直後の解放、日英ルール、初期6枠。
- MOD説明の日英ローカライズと複数行、生成・作者クレジット、5人＋サタンだけのCafeParadeカテゴリ、ほかのカードとMOD一覧のCafetro!表記を確認。
- スキン4スート・2配色、画像全52セル。統合元のトランプ4枚をSHA-256で照合。
- nearest/lanczos、1x/2xのアトラス全画素・透明度・サタン前景・MODアイコン。配布する追跡済み画像とnearest再生成結果も一致。

- **展開した配布ZIPだけ**を読み、ジョーカー12種・お題6種・スキン4種と全アトラスを登録。内部IDを保持し、追加の開発ファイルに依存しないことを確認。
- 作者のREADME.txtが必ず同梱され、旧SAKI_CARDS_NOTICE.txtが入らないことを確認。追加のMarkdown READMEも同梱できる。

ロジックは合計1,315アサーション。モックはゲームの描画・セーブ形式・Steamoddedディスパッチ全体を再現しません。ZIPの読み込み確認も、実ゲーム起動の代用ではありません。
