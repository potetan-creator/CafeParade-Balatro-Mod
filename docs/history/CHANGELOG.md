# 開発履歴（旧構成）

リリース整備前の変更記録です。パス・ファイル数・お試しライブの案内は当時の内容です。現在の構成は `../DEVELOPMENT.md` を参照してください。

## v1.0.0 の変更

- 5人それぞれが主役の**ソロお題5つ**を追加。各メンバーを1枚、エターナルで初期所持し、他の4人とサタンを禁止。スプラッシュ・ロールケーキ・マーブル・ケーキセットなどを組み合わせ、資金・ディスカード・手札・スロットの縛りを変えています。
- 同じプロフィールで5つをすべてクリアすると、**Café Parade：悪魔のフルコース**を解放。5人＋サタンをエターナルで固定し、2ハンド・1ディスカード、パープルステーク相当のスコア上昇、利息と残りハンド報酬なしで挑みます。追加ジョーカーの入手経路も制限しています。
- お題名・追加ルールは日英対応。初期所持、全設定、攻略の軸と解放条件は **[CHALLENGE_GUIDE.md](CHALLENGE_GUIDE.md)**。お試しライブも残しています。
- 追加407件を含む合計1,066件のロジック検証、Lua 5.1構文・画像・スキン登録の検証が通過。実ゲームでの難易度と表示は未確認です。

## v0.6.1 の変更

- **THREE ONE FIVE** の条件を修正。プレイしたハンドに **3と5の両方** が含まれ、そのうち少なくとも1枚が得点すると **X3.15**。3のペア＋得点しない5、5のペア＋得点しない3でも発動します。3と5のどちらも得点しない場合や、片方を手札に残した場合は発動しません。
- 日英の説明を修正。説明末尾の元ネタ表記と画像配置は維持しています。

## v0.6.0 の変更

- **THREE ONE FIVE** を追加。レア・購入価格$8。得点するカードに **3または5** が少なくとも1枚あれば、ジョーカーの得点処理で **X3.15**。該当カードが複数でも基本発動はハンドにつき1回です。無効化されたカード・ストーン・得点しないカードは数えません。Blueprint/Brainstormとジョーカー再発動に対応します。
- `315_joker.png` を使用。日英の説明末尾へ、小さなグレー文字で「アイドルマスターSideM×FiFS展 THREE ONE FIVE」を記載しました。
- アトラスと一覧プレビューを **横5枚で折り返す2段配置** に変更。1xは355×190、2xは710×380です。追加時も5枚ごとに次の段へ進みます。サタンの前景は独立したレイヤーを維持します。

## v0.5.0 の変更

- **ロールケーキ / Plain cakeroll** を追加。コモン・購入価格$4で、得点対象がちょうど2枚のとき、その2枚へ得点ごとに **+30チップ** を与えます。説明は既存カード風の日英本文だけです。
- 判定はプレイ枚数ではなく得点対象の枚数です。5枚プレイしてもペアの2枚だけが得点する場合は合計+60チップ。得点対象が1枚・3枚以上なら発動しません。レッドシールや巻緒による再発動、Blueprint/Brainstormにも適用されます。
- `Plain_cakeroll_joker.png` を原稿へコピーし、アトラス末尾の `x=8,y=0` に追加しました。1xは639×95、2xは1278×190です。既存8枚の座標・画像は維持しています。サタンのメンバー数とお試しライブの初期6枚には追加していません。

## v0.4.2 の変更

- 咲の説明を、Balatroの既存カードで使われる「プレイした最初のカード」「得点時」の表現に合わせました。日英とも、最初のカードが未強化の場合に変化することを本文で示します。

## v0.4.1 の変更

- 咲のワイルド化は、**プレイしたカードの一番左が未強化の場合だけ**発動します。左端がワイルドやほかの強化カードなら不発になり、ブラインドの使用回数は残ります。
- 判定はプレイしたカード全体の順序を使います。得点対象外でも左端が未強化なら対象です。プレーンなカードを中央・右へ置けば、そのハンドでは変化しません。
- Makeup! → ワイルド化 → 得点演出の順序、シール・エディション保持、ブラインドごとに1回の制限は維持しています。日英の本文も更新しました。

## v0.4.0 の変更

- 曲にちなむ **Chocolate Spacial** を追加。レア・購入価格$8で、名前は日英とも同じ表記です。説明は日英対応、追加の補足ツールチップはありません。
- 役が **フラッシュハウス** のハンド終了後に、ランダムなスペクトルカードを2枚生成します。空きが1枠なら1枚、満杯なら生成しません。フルハウス・フラッシュ・フラッシュファイブでは発動しません。
- Blueprint/Brainstormも対応。コピー・複数所持・神谷のタロット生成は消耗品の予約枠を共有し、枠を超えて生成しないようにしています。同じハンドの重複評価やジョーカー再発動では追加生成しません。
- `Chocolate_spacial_joker.png` を原稿へコピーし、アトラス末尾の `x=7,y=0` に追加。1xは568×95、2xは1136×190です。既存7枚の画像・座標を維持し、サタンのメンバー数とお試しライブの初期6枚には追加していません。

## v0.3.0 の変更

- コモンジョーカー **ケーキセット / Cake Set**（購入価格$4）を追加。画像は `Cake_set_joker.png`、名前・説明・補足は日英対応です。

- ボス全体は無効化せず、ほかの制限や別原因のカード無効化は残します。ワイルドや手札のスチールにも適用し、得点後に通常の制限へ戻します。咲との左右の順序には依存しません。
- ケーキセットはCafé Paradeメンバー数に含まず、Blueprint/Brainstormのコピー対象外です。複数所持でも解除範囲は増えません。
- 画像を既存6枚の後ろ（`x=6,y=0`）へ追加し、1xを497×95、2xを994×190へ拡張しました。既存カードの座標は維持しています。お試しライブの初期所持は従来の6枚です。
