# ソロお題と「悪魔のフルコース」

v1.0.0で、5人それぞれのお題と、全員クリア後の最終お題を追加しました。通常のお題と同じく、アンティ8のボス撃破を目指します。

## 始め方と解放条件

更新後にゲームを再起動し、チャレンジ一覧から選んで新しいランを開始します。5人のソロお題は最初から選択できます。本体側のチャレンジメニューは、プロフィールで解放しておく必要があります。

**同じプロフィールで5つのソロお題をすべてクリア**すると、**Café Parade：悪魔のフルコース**が解放されます。クリア順は自由です。通常ランの勝利は解放条件に数えません。未解放の最終お題は、標準のお題一覧ではロック表示になります。

クリア記録には本体のプロフィール保存を使用します。別プロフィールの記録を合算したり、進行を自動で書き換えたりしません。Steamodded標準の「すべて解放」を使ったプロフィールでは、標準の仕様に従ってロックが解除される場合があります。

## 最終お題：悪魔のフルコース

5人とサタンの**6枚すべてをエターナルで初期所持**します。

- 標準52枚デッキ、手札7枚、**2ハンド・1ディスカード**。
- 基本ジョーカースロット5＋サタンの1枠＝6枠。初期6枚で満杯です。
- 要求スコアの上昇率は**パープルステーク相当**。ほかのステーク特有の制限は追加しません。
- 所持金$4。**利息・残りハンドの報酬なし**。ブラインドの通常報酬と神谷の収入は得られます。
- ショップのジョーカー、バフーンパック、ジョーカーを与えるタグ、審判・レイス・ソウル・アンクを禁止。反物質とエクトプラズムも禁止し、6人の構成を固定します。
- タロット・惑星・トランプの強化でデッキを育てます。消耗品枠は標準の2枠、初期消耗品はありません。
- 全員エターナルでジョーカーを売れないため、売却で解除するヴァーダントリーフは出現しません。

v1.1.0では神谷が条件を満たすハンドごとに$3を得られ、サタンの初期倍率は5人時にX3.75です。スキップすると神谷の収入と咲のワイルド化の機会が減ります。3スーツで神谷の収入を取りつつ、ペアで東雲を育て、左端の2枚を巻緒で再発動。咲のワイルドと強化カードで乗算を重ね、ボス撃破でサタンを成長させてください。ケーキセットは初期構成に含まれません。

実ゲームでの難易度、クリア可能性、メニュー表示と文章の収まりは未確認です。ゲームへの導入・プレイ確認はユーザー側で行います。能力確認用のお試しライブは開発テストのfixtureへ移し、配布版から外しています。
