# ソロお題と「悪魔のフルコース」

v1.0.0で、5人それぞれのお題と、全員クリア後の最終お題を追加しました。通常のお題と同じく、アンティ8のボス撃破を目指します。

## 始め方と解放条件

更新後にゲームを再起動し、チャレンジ一覧から選んで新しいランを開始します。5人のソロお題は最初から選択できます。本体側のチャレンジメニューは、プロフィールで解放しておく必要があります。

**同じプロフィールで5つのソロお題をすべてクリア**すると、**Café Parade：悪魔のフルコース**が解放されます。クリア順は自由です。通常ランの勝利は解放条件に数えません。未解放の最終お題は、標準のお題一覧ではロック表示になります。

クリア記録には本体のプロフィール保存を使用します。別プロフィールの記録を合算したり、進行を自動で書き換えたりしません。Steamodded標準の「すべて解放」を使ったプロフィールでは、標準の仕様に従ってロックが解除される場合があります。

## 最終お題：悪魔のフルコース

5人とサタンの**6枚すべてをエターナルで初期所持**します。

- 標準52枚デッキ、手札7枚、**2ハンド・1ディスカード**。
- 基本ジョーカースロット5＋サタンの1枠＝6枠。初期6枚で満杯です。
- 要求スコアの上昇率は**パープルステーク相当**。ほかのステーク特有の制限は追加しません。
- 所持金$4。**利息・残りハンドの報酬なし**。ブラインドの通常報酬と神谷の収入は得られます。
- ショップのジョーカー、バフーンパック、ジョーカーを与えるタグ、審判・レイス・ソウル・アンクを禁止。反物質とエクトプラズムも禁止し、6人の構成を固定します。
- タロット・惑星・トランプの強化でデッキを育てます。消耗品枠は標準の2枠、初期消耗品はありません。
- 全員エターナルでジョーカーを売れないため、売却で解除するヴァーダントリーフは出現しません。

v1.1.0では神谷が条件を満たすハンドごとに$3を得られ、サタンの初期倍率は5人時にX3.75です。スキップすると神谷の収入と咲のワイルド化の機会が減ります。3スーツで神谷の収入を取りつつ、ペアで東雲を育て、左端の2枚を巻緒で再発動。咲のワイルドと強化カードで乗算を重ね、ボス撃破でサタンを成長させてください。ケーキセットは初期構成に含まれません。

## 動作確認用：葛之葉雨彦：ネガティブ動作確認

チャレンジ一覧から選択できます。お題クリアによる個別の解放条件はありません。所持金$50、6ハンド・6ディスカード・手札8枚。デッキは8枚だけで、ネガティブのハート2が必ず初手に含まれます。

初期ジョーカーは、ネガティブの雨彦・ネガティブの原作ジョーカー・通常のジョリージョーカー。消耗品はネガティブの「力」と「冥王星」、通常の「吊られた男」です。エターナルは付けず、売却できます。

|確認する操作|ネガティブ所持数|雨彦の倍率|
|---|---:|---:|
|開始時|5|X2.25|
|ネガティブの「力」を使用|4|X2.00|
|ネガティブの「冥王星」を使用|3|X1.75|
|「吊られた男」でネガティブのハート2を破壊|2|X1.50|
|ネガティブの原作ジョーカーを売却|1|X1.25|

通常のジョリージョーカーを売っても、ネガティブの枚数と倍率は変わりません。ネガティブな消耗品やトランプが得点に参加しない状態でも、所持していれば数えます。雨彦の前景が元の色のまま固定され、背景だけにネガティブ加工がかかること、拡大表示・ドラッグ・裏向き・セーブ再開でも問題がないことも確認してください。

原作のチャレンジ生成は消耗品のeditionフィールドを使わないため、専用applyの非ブロックイベントで初期2枚をネガティブにします。初期カード生成を妨げず、初期化済み状態をランへ保存し、繰り返しの適用や別ランへのイベント残留では再生成・再加工しません。通常ランや既存6つのお題にこの初期化は適用しません。

## 北村想楽のChun-Chun動作確認

チャレンジ一覧から **北村想楽：Chun-Chun動作確認** を選びます。初期の並びはBlueprint・想楽・雨彦で、13枚すべてが初手にそろいます。

| 操作 | Chun-Chunシール | 雨彦の倍率 |
|---|---:|---:|
| 開始 | 0枚 | ×1.5 |
| ハートの2を単独でプレイ | 3枚 | ×2 |
| ハートの3を単独でプレイ | 6枚 | ×2.75 |
| ハートの4を単独でプレイ | 9枚 | ×3.5 |

ダイヤの2は初めからネガティブです。シールが付いた後も、雨彦はダイヤの2を1枚として数えます。想楽を売却してからシール付きのカードを得点させると、シールの倍率+5を確認できます。ラウンドが終わるとChun-Chunだけが消え、ハートの5にあるレッドシールとダイヤの2のネガティブは残ります。ダイヤの2を破壊していなければ雨彦は×1.5に戻ります。
