# Cafetro! 変更履歴

## 未リリース

正式版v1.0.0以降の変更を蓄積する欄です。次の正式バージョン番号は、リリース指示時に確定します。現時点ではv1.1.0・v1.2.0の候補下書きに含まれています。

- 北村想楽とChun-Chunシールを追加。得点後に条件を満たすトランプへ付与し、得点時は倍率+5。ラウンド中は最大9枚で、雨彦はネガティブ相当として数える。
- 想楽・Blueprint・雨彦を初期所持する動作確認用チャレンジを追加。
- 雨彦の前景を再アップロードされた最新のAmehiko_joker.pngへ差し替え、1x／2xと画像一覧を再生成。
- サタンの説明を日英とも6行から4行へ整理。エンボスジョーカーも短くし、今後のシンプルな効果は短い原作風の説明に統一。
- エンボスジョーカーの日本語説明の末尾を「倍率+4」に短縮。
- 葛之葉雨彦（レア・基本価格$8）を追加。必ずネガティブで出現し、自身・消耗品・トランプを含む所持ネガティブ1枚ごとに基礎X1へ0.25加算。キャラクターの色を反転させず、浮遊しない固定前景を追加。
- 依頼に基づき雨彦の動作確認用チャレンジを追加。初手8枚・ネガティブ5枚・初期X2.25から、売却・消費・破壊と描画を確認できる。
- ケーキセットを「ペアを含む役」へ拡張。ラウンド終了時に1/5で食べられるフードジョーカーへ変更。
- ロールケーキを得点2枚の各+50チップへ調整。ラウンド終了時に1/10で食べられるフードジョーカーへ変更。
- ケーキセット／ロールケーキの有効所持中、巻緒の抽選重みを1.25倍にする隠し効果。両方・複数所持でも重複せず、説明文には表示しない。
- エンボスジョーカー（コモン）：得点する強化カードごとに倍率+4。再発動にも適用。
- 金人間 / Goldpeople（レア・$8）：所持中、原作の道化師パックからコモンを除外。他MODのパックやショップには適用しない。
- スンスン（アンコモン）：得点する6を2回追加で再発動。説明末尾に非公式ファンアート表記。
- ジョーカー画像を5列×3段へ拡張。
- 神谷幸広のブラインドごとの発動制限を撤廃。条件を満たすハンドごとに$3とタロット抽選。
- サタンの初期倍率をX2からX2.5へ上方調整。
- 東雲・サタンの倍率増加量を赤枠にし、現在倍率を説明の末尾へ統一。
- 咲の説明を「プレイした一番左のカード」に変更。効果の条件は維持。
