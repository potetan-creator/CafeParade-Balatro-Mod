# Cafetro! 変更履歴

## 未リリース

正式版v1.0.0以降の変更を蓄積する欄です。次の正式バージョン番号は、リリース指示時に確定します。現時点ではv1.1.0・v1.2.0の候補下書きに含まれています。

- エンボスジョーカー（コモン）：得点する強化カードごとに倍率+4。再発動にも適用。
- スンスン（アンコモン）：得点する6を2回追加で再発動。説明末尾に非公式ファンアート表記。
- ジョーカー画像を5列×3段へ拡張。
- 神谷幸広のブラインドごとの発動制限を撤廃。条件を満たすハンドごとに$3とタロット抽選。
- サタンの初期倍率をX2からX2.5へ上方調整。
- 東雲・サタンの倍率増加量を赤枠にし、現在倍率を説明の末尾へ統一。
- 咲の説明を「プレイした一番左のカード」に変更。効果の条件は維持。
